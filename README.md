# java-racingcar-precourse

## 구현 기능 목록

- [x] 자동차 이름 입력 및 유효성 검사
    - 이름은 쉼표(`,`)로 구분
    - 각 이름은 1~5자
    - 잘못된 입력 시 `IllegalArgumentException` 발생 및 프로그램 종료

- [x] 시도 횟수 입력 및 유효성 검사
    - 숫자가 아닐 경우 예외 발생
    - 1회 이상만 허용

- [x] 자동차 전진 로직
    - 0~9 사이 랜덤값 중 4 이상일 때 전진
    - `camp.nextstep.edu.missionutils.Randoms` 활용

- [x] 차수별 실행 결과 출력
    - 각 자동차 이름과 전진 결과 출력

- [x] 우승자 안내 문구 출력
    - 가장 멀리 간 자동차 우승자 선정
    - 공동 우승 시 쉼표로 구분하여 출력
